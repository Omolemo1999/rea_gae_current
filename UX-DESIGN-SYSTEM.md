# ReaGae UX design system

The rider verification page is the visual reference for the application.

- Use square/flat surfaces; no pill or circular UI containers.
- Prefer sections, dividers and strong typography over nested cards.
- Keep the purple/indigo verification visual language and light grey page background.
- Forms and tables should use crisp borders and generous spacing rather than shadows.
- All primary workflows must work on narrow mobile screens as well as desktop.
- Face verification uses the browser/device `getUserMedia` permission flow and requests camera access as soon as the secure verification session is prepared.
- Deployed camera verification must be served over HTTPS (localhost is allowed by browsers for local development).
- Route and network loading use the ReaGae car loading animation.
